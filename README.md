# Timber Game using SFML

A 2D Timber-style game developed in C++ using the SFML library.

## Features
- Animated clouds and bee movement
- Dynamic branch generation
- Sound effects
- Time bar system
- Collision detection
- Pause and restart functionality

## Technologies Used
- C++
- SFML

## Controls
- Left Arrow → Chop Left
- Right Arrow → Chop Right
- Enter → Start/Restart
- Space → Pause

## How to Run

Compile using:

```bash
g++ main.cpp -o timber -lsfml-graphics -lsfml-window -lsfml-system -lsfml-audio
```

Run:

```bash
./timber
```
